## 제출 폼에서 확인된 추가 조건 (2026-08-07)

- 업로드 **최대 5개 파일 / 파일당 10MB** → 게임 ZIP 외에 **스크린샷·GIF를 별도 파일로** 낼 수 있다.
  (단 홍보 파일을 게임 ZIP 안에 넣으면 1.44MB에 합산되니 반드시 분리)
- **소스코드 제출 의무 없음.** 플랫폼 제한 없음(Win/Mac/Linux) — 그래도 Windows 단일 빌드 권장.
- **한/영/일 3개 국어 국제 공모전** → 게임 내 텍스트는 **영어 기본**. 한글 폰트 안 넣어 용량도 절약.
- **수상작은 2P GAME ARCADE 전시회에 전시될 수 있음** → **전시 친화적 설계가 숨은 가산점**
  (게임패드/키보드 전용, 어트랙트 모드 자동 리셋, 설명 없이 이해 가능). `02-심사기준분석.md`

## 엔진 결정 — 실측 완료 (2026-08-07) ✅

> ### **C + raylib 5.5 (config 트림 + GLFW + GL3.3, 정적 링크, `-Os`, Windows x64 단일 exe)**
> **엔진 실측 502,272 바이트 → 에셋 예산 972,288 바이트 확보 (한도의 66%)**
> **✅ Wine 실행 검증 통과** (셰이더·텍스처·FBO·폰트 정상)

실측 근거 (Windows x64 PE 직접 빌드 + Wine 실행): `08-엔진실측결과.md`

- ❌ **SDL2는 `SDL2.dll` 하나가 1,598,976 바이트** — 게임 코드 0바이트여도 실격
- ❌ LÖVE 11,410,931 / Godot 템플릿 97,496,576 — 논외
- ❌ **RGFW 백엔드(331,776)는 −170KB로 크기는 1등이었으나 크래시** — 채택 보류
- ℹ️ 손으로 코드 발췌는 무의미 — `--gc-sections`가 이미 오브젝트의 80%를 버린다
- ℹ️ **크기만 재고 엔진을 고르면 안 된다** — 이번에 RGFW로 그럴 뻔했다
