## 항목별 절약 기법

### 실행 파일
- MSVC: `/O2 /MT /GL` + 링커 `/LTCG /OPT:REF /OPT:ICF`
- GCC/Clang: `-Os -flto -ffunction-sections -fdata-sections -Wl,--gc-sections -s`
- raylib `config.h`에서 미사용 모듈 OFF (rmodels, 안 쓰는 이미지/오디오 포맷 로더)
- C++ 쓸 거면 예외/RTTI 끄기 (`/EHs- /GR-`, `-fno-exceptions -fno-rtti`) — STL 의존 줄이기
- **UPX 등 실행파일 패커는 쓰지 않는다** (규칙 해석 리스크, `01-규칙원문.md` 참고)

### 그래픽 — 가장 크게 아낄 수 있는 영역
| 기법 | 효과 |
| --- | --- |
| **절차적 생성** (코드로 도형/노이즈/그라디언트) | 사실상 0바이트 |
| 저해상도 도트 (16×16, 32×32) + 정수 스케일업 | 원본 대비 1/10 이하 |
| **8bit 인덱스 PNG (팔레트 16~32색)** | 트루컬러 대비 1/4 |
| 스프라이트를 한 장 아틀라스로 통합 | PNG 헤더/파일 오버헤드 제거 |
| 좌우 대칭 캐릭터는 반쪽만 저장 후 미러링 | 50% |
| 색 변형은 셰이더/팔레트 스왑으로 (에셋 복제 금지) | N배 절약 |
| PNG 최적화: `oxipng -o max --strip all`, `pngquant` | 20~50% 추가 |
| 애니메이션은 프레임 대신 코드 변형(회전/스케일/스쿼시) | 대폭 |

### 음악 — 두 번째로 큰 영역. **여기서 실패하면 용량이 터진다**
| 방식 | 3분 곡 기준 | 판정 |
| --- | --- | --- |
| WAV 44.1kHz 스테레오 | ~30MB | ❌ 절대 금지 |
| MP3/OGG 128kbps | ~2.8MB | ❌ 불가 |
| OGG 48kbps 모노 | ~1MB | ❌ 불가 |
| **트래커 모듈 (.xm / .mod / .it)** | **20~150KB** | ✅ **정답** |
| **런타임 절차적 합성 (칩튠 신스 직접 구현)** | **~0KB** | ✅✅ 최상 |
| MIDI + 내장 소프트신스 | 5~20KB + 신스 코드 | ✅ 가능 |

- raylib은 **XM / MOD 재생을 기본 지원**한다 (`LoadMusicStream`). 이걸 쓴다.
- 작곡 툴: OpenMPT, MilkyTracker (무료). 샘플을 짧고 적게 — 샘플이 곧 파일 크기.
- 최고 효율: **간단한 칩튠 신스(펄스/삼각/노이즈 + ADSR)를 직접 구현**하고 곡은 음표 배열로.
  → 곡 하나가 2~5KB. 무한히 늘려도 용량 부담 없음.

### 효과음
- **런타임 절차적 생성이 정답.** rFXGen / sfxr 파라미터(수십 바이트)만 저장하고 코드로 합성.
- 파일로 넣어야 한다면 8bit 11kHz 모노 WAV (짧게, 0.3초 이하).

### 폰트
- TTF 동봉(수백 KB) ❌ → **비트맵 폰트 아틀라스** 또는 **코드에 박은 비트 폰트**
- 한글을 쓸 거면: 완성형 전체(11,172자) 불가. **필요한 글자만 추출**하거나
  **조합형 비트맵(초·중·종성 세트)**을 쓴다. 또는 **영문/숫자만 쓰는 UI 설계**로 회피.
- 최소안: 8×8 ASCII 비트맵 = 96자 × 8바이트 = **768바이트**

### 데이터
- 레벨을 절차적으로 생성 (시드 = 4바이트)
- 수동 레벨은 문자열 맵 + 런타임 압축(zlib/LZ4)
- JSON ❌ → 바이너리 또는 컴팩트 텍스트

## 용량 감시 자동화 (반드시 세팅)

빌드 스크립트 끝에 붙여 매 빌드마다 확인:

```bash
#!/usr/bin/env bash
# tools/check-size.sh
LIMIT=1474560
TARGET=1400000
DIST="${1:-dist}"

TOTAL=$(find "$DIST" -type f -printf '%s\n' | awk '{s+=$1} END {print s+0}')
PCT=$(awk -v t="$TOTAL" -v l="$LIMIT" 'BEGIN{printf "%.1f", t*100/l}')

echo "── 용량 리포트 ──"
find "$DIST" -type f -printf '%10s  %p\n' | sort -rn
echo "합계: $TOTAL / $LIMIT 바이트 (${PCT}%)  여유: $((LIMIT-TOTAL))"

if   [ "$TOTAL" -gt "$LIMIT" ];  then echo "❌ 실격: 상한 초과"; exit 1
elif [ "$TOTAL" -gt "$TARGET" ]; then echo "⚠️  경고: 안전 목표($TARGET) 초과"; exit 0
else echo "✅ 통과"; fi
```

- CI(GitHub Actions)에도 넣어 **초과 시 빌드 실패**로 만든다.
- 주 1회 `docs/` 또는 커밋 메시지에 용량 추이를 기록해 증가 속도를 감시한다.
