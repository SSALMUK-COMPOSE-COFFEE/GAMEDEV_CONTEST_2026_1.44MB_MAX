# 기획 전략 — 어떤 게임을 만들어야 상을 타는가

## 대전제

**28일 × (팀 여력) 안에 "완성"까지 가야 한다. 스코프가 곧 수상 확률이다.**
1.44MB 제약에서 이기는 게임은 "에셋이 적어도 되는 장르"다.

## 용량 대비 효율이 높은 장르 (추천)

| 장르 | 왜 좋은가 | 리스크 |
| --- | --- | --- |
| **아케이드 스코어 어택** (슈팅/뱀서라이크/피하기) | 스테이지 데이터 불필요, 절차적 생성, 1판 3분, "한 판 더" | 오리지널리티 확보 필요 |
| **퍼즐** (연쇄/물리/논리) | 룰 자체가 콘텐츠. 스테이지가 텍스트 몇 KB | 좋은 룰 발명이 어려움 |
| **로그라이크 / 덱빌더** | 아이템·이벤트 조합으로 플레이타임 폭발, 데이터는 텍스트 | 밸런싱 시간 많이 먹음 |
| **리듬 게임** | 절차적/알고리즘 채보 + 칩튠이면 소용량 | 음악 퀄리티가 곧 게임 퀄리티 |
| **타워 디펜스 / 자동전투** | 에셋 재사용률 최고 | 첫 60초 임팩트가 약함 |

## 피해야 할 장르

- ❌ **스토리 중심 어드벤처 / 비주얼 노벨** — 텍스트는 싸지만 일러스트/컷신이 용량을 먹고, 심사에서 "게임성" 평가가 어렵다.
- ❌ **오픈월드 / 대규모 RPG** — 28일 안에 절대 완성 불가.
- ❌ **3D 액션** — 모델·애니메이션 용량 + 제작 시간 이중고.
- ❌ **멀티플레이어** — 심사자가 혼자 돌려본다. 아무도 못 논다.

## 1.44MB 제약을 "컨셉"으로 승화시키기 (가산점 포인트)

심사 기준에 명시되진 않았지만, **제약 자체를 테마로 끌어들인 작품은 기억에 남는다.**

아이디어 예시:
- 플로피 디스크 / 90년대 PC / DOS 부팅 화면 감성의 UI
- "디스크 용량이 곧 게임 내 자원" — 아이템을 얻으면 저장 공간을 먹는 인벤토리
- 도스 시절 EGA/VGA 16색 팔레트 제한을 아트 디렉션으로 채택
- 로딩·저장을 플로피 드라이브 소리로 연출

> 단, **컨셉이 재미를 대체하지 못한다.** 게임플레이가 먼저다.

## 스코프 기준선 (이 이상 넘지 말 것)

| 요소 | 상한 |
| --- | --- |
| 코어 메커닉 | **1개** (+ 파생 변주 2~3개) |
| 적/오브젝트 종류 | 6~8종 |
| 스테이지/웨이브 | 절차적 생성 우선. 수동 제작은 10개 이하 |
| 보스 | 1~2체 |
| BGM | 2~3곡 (타이틀 / 인게임 / 엔딩) |
| SFX | 10~15종 (절차적 생성 권장) |
| 총 플레이타임 | 15~30분 (반복 플레이로 연장) |

## 아이디어 확정 절차 (D-27까지 끝낼 것)

1. 후보 3개를 각각 **한 문장**으로 적는다. ("당신은 ___이고, ___해서, ___한다")
2. 각 후보의 **첫 60초 시나리오**를 초 단위로 적는다.
3. 각 후보의 **용량 예산 초안**을 뽑는다 (`05-용량예산.md`).
4. 가장 스코프가 작은 것을 고른다. — **야심찬 것을 고르면 진다.**
5. 확정 후 **기능 추가 금지 선언(Feature Freeze는 D-10)**.
